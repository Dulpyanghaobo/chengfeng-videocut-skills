# 暗黑动作漫画

本 fork 的本地定制版，默认深石墨舞台与原创工帽工人。基于成峰 / AI产品自由的 [chengfeng-videocut-xiaohei](https://github.com/Agentchengfeng/chengfeng-videocut-xiaohei) 固定源码改编；上游身份和文件摘要见 `upstream-source.json`。视觉方法参考 Ian Xiaohei，非官方合作，不含其原图或角色源文件。保留 `LICENSE`、`NOTICE.md`、`UPSTREAM-NOTICE.md` 及第三方许可。

## 从已有内容开始

- 已有稳定文稿、原声和字幕就复用，先看原片。画面清楚则保留；注意力需要引导则标注；抽象概念才采用动作隐喻。真实证据和精确工程关系保留来源与适当表现方式。
- 先写清观众要理解什么，以及「谁操作什么 → 输入或状态如何改变 → 出现什么结果」。围绕完整动作安排镜头，允许跨多句字幕；不按字幕页生成一张结论卡。
- 画幅沿用用户或工程设置。当前竖屏示例为 1080×1920；横屏内容重新构图，保持角色比例。暗色是本 fork 的默认选择，用户指定其他主题时优先遵循用户。

## 设计与制作

1. 设计前读 [风格与角色](references/style-rules.md)，实现前读 [分层](references/svg-layering.md) 和 [时间驱动](references/motion-rules.md)。
2. 先画具体 State A/B：对象位置、接触点、事件路径、字幕安全区。实际查看原尺寸与手机尺寸，再实现代表性短动态原型；连续审看后扩展。
3. 默认从 `assets/templates/xiaohei-dark-motion/` 复制到工程的输出目录。先改隐喻、对象和构图，再改角色动作与批注；模板是可运行示例，不是每期固定工厂版式。旧白底示例保留在其他模板目录，按明确需要选用。
4. 原创工人必须参与搬运、操作、分配或承接。移除角色会破坏解释才有保留理由。肩膀低于眼睛，肘部弯曲，中间姿态不穿脸；设备响应须发生在输入抵达后。
5. 语义对象单独成组。短批注跟随动作出现，结果保持到下一段需要它时。少量蓝灰说明与琥珀色动作提示；颜色与位移、转动、疏密共同表达状态。
6. 时间只由可定位的播放位置驱动，支持反向 seek、重复 seek、静态审看。示例的十秒时刻仅用于演示；配口播时改为真实 cue，并验证映射和层边界。接入已有 Remotion 项目时用帧状态实现这些动作，沿用该工程时间轴。

## 输出与验收

输出可编辑源文件、依赖许可、静态预览和动态预览；有口播时保留真实 cue、原声与素材来源。记录版本、审看文件摘要、实际结论及未做的检查。渲染和连续播放均通过后才标记对应范围完成；截图只证明构图。

在普通速度和手机尺寸下查看：操作接触 → 输入抵达 → 设备响应 → 输出；检查倒回起点不会留下未来批注，隐藏字幕也能看出状态差异。不得把类比数量换算成模型参数或测试结论。

## 工程接入边界

本目录是可下载的本地创作 Skill，不修改本仓固定发布的 Plugin 或安装 pin。只检查当前任务已指定的工作台和接口；需要接入时读 `references/shared/plugin-access.md`，按实际提供方核验项目与能力。示例的 `videocut:seek` 接收器只是时间驱动适配点；文件可播放不代表已进入工作台。本次源码定制不启动或升级 Runtime，也不声称完成工作台端到端验收。
