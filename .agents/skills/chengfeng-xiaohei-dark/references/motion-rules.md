# 暗黑版时间与动作规则

本文件为 fork 改编；动作方法来源见 `../NOTICE.md`。

一个镜头解释一个完整语义动作。语义分组包括 `worker`、`machine`、`inputs`、`outputs`、`annotations`；标签不会在时间零同时全部出现。

## 可重复时间驱动

- 本地预览使用暂停的 GSAP 时间线，仅用户点击播放时推进；嵌入默认暂停，由 `videocut:seek` 消息驱动。导出或批量截图调用 `window.renderAt(seconds)`。
- 每次 seek 从时间推导完整画面，包括全部对象的显隐、位置与转角。反向 seek 必须还原输入和批注，不能依赖播放过某个回调才能初始化。
- 不用 `Date.now()`、CSS animation/transition 或随机逐帧抖动控制动画。Remotion 接入使用 frame/fps；不要再造一条剪辑时间轴。
- 示例 `motion.mjs` 是十秒演示时刻。生产要用真实口播 cue，校验先后、覆盖范围和层长；不要平均分配字幕时长。已建立状态跨字幕继承。

## 接触与因果

手与开关接触以后才亮操作端；纸张从手持点松开后落到传送带，再进入设备。齿轮从输入到达时开始，输出在处理后出现。间歇设备处理一单后停止；持续设备有连续输入、设备转动和输出共同作证，不能只改颜色。

## 固定轴

滚轮和齿轮使用 SVG 属性 `transform="rotate(angle cx cy)"`，外层平移固定轴位置。不要同时添加 CSS transform-origin / transform-box 或 GSAP svgOrigin，避免二次轴心补偿。查看多个中间帧，轮心应保持不动。

## 连续审看

先查看 State A/B 构图与角色中间姿态，再播放最关键短原型；通过后扩展。全段普通速度和手机尺寸检查操作、响应、结果、节奏与字幕。无字幕也应能看出相同规模和不同工作量。成功加载 HTML 和通过结构校验不能代替实际视频验收。
