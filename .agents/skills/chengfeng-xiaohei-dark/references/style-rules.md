# 暗黑动作漫画与原创工人

本文件为 fork 改编，替代上游白底默认。上游白底模板仍保留，暗色版本使用 `assets/templates/xiaohei-dark-motion/theme.mjs` 的单一配色源。

| 用途 | 颜色 |
| --- | --- |
| 舞台 | `#10171D` 深石墨 |
| 物体表面 | `#1C2932` |
| 主要线条与文字 | `#DFE7E4` 灰白 |
| 次要文字 | `#91A4AD` |
| 背景说明与订单 | `#87BAC9` 蓝灰 |
| 当前操作、持续负载 | `#F1AD69` 琥珀 |
| 有依据的风险 | `#ED8B85` |

保持留白与单一动作焦点。画幅来自任务；示例 9:16，其他画幅要重新构图。不要固定标题栏、结论卡、网格仪表盘或技术面板，不添加霓虹发光、粒子、渐变或纹理。

## 原创工人

工帽有浅灰壳与短琥珀帽檐，脸部为深色面罩和两只浅色眼睛；工装为蓝灰短外套、小口袋；手套琥珀色，四肢为浅色弯曲线条。保持克制的表情与略笨拙的工人姿态，不做旁观吉祥物。`worker-prototype.svg` 是角色比例依据，不是 Ian 原始角色文件。

- 手臂从脸下方身体侧面伸出，肘部有弧度，臂长不超过身高的 0.8 倍；远处操作先走近。
- 手持物与手掌共用坐标；松手后物体沿接得上的入口路径移动。
- 操作端接触后才改变开关状态；输入抵达后再转动设备；处理后再输出。
- 检查携单、伸手、接触及其间姿态，浅色轮廓不能和帽檐、眼睛或另一只手混在一起。

说明字尽量 2–8 字、最多同时承载一个认知重点，按动作阶段出现。表意已由物体运动完成时不再叠加箭头。暗色背景下以手机尺寸检查低对比细线、标签和字幕。

车身外观使用精细图片；代码几何适合工厂隐喻和语义对象，不替代真实汽车证据。类比保持清楚的适用范围。
