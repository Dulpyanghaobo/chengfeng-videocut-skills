# 公共视频资源

可被剪辑任务引用的独立模板；不增加 Plugin 的业务入口，也不修改已发布安装快照。

- [辅助驾驶系列 · 标准开头 1 · V2](skills/adas-series-intro/SKILL.md)：1080×1920 / 60fps / 16.333秒；四图车型槽 → 俯视能力进化与红色 ERROR → 论文 → 四维 → 右侧可填方案的五档。每期先询问车型、顺序、已讲方案档位和本期是否揭晓，公共默认配置不保存历史评级。含纯帧 SVG、被动 HTML 模块、图片配置与高清渲染，V1 配置仍可用。
- [ADAS二维动效公共组件 v1](components/adas-motion-2d/v1/README.md)：精细俯视车辆/骑行者、连续道路、感知跟踪、Bezier轨迹、平面模型核心及反馈回路；公共几何与业务字幕/训练逻辑分开。含品牌无关演示、被动HTML资源、横竖版与乱序seek检查，首个业务消费者为Momenta R7。

这些资源直接从本地仓库路径读取；放入 `common` 不代表已激活新的插件版本或自动进入 Runtime 工程。原生工程的画面添加、审核和导出继续使用已安装的 `chengfeng-visual`、工作台与导出入口。

标准开头五档右侧现支持官方芯片图片，单／双颗按数量显示；内置 Orin、Thor、图灵素材和来源记录，原文字版配置仍可用。
